# 🏨 Elite Suites: Smart Hotel Discovery Platform

## 🌟 Project Overview

Elite Suites is an innovative Java-based hotel search application that revolutionizes how users find and book hotels through cutting-edge search technologies and intelligent data processing.

## ✨ Key Features

### 🔍 Intelligent Search Capabilities
- **Multi-Dimensional Search**
  * Hotel Name Search
  * City-based Discovery
  * Feature-based Filtering
  * Price Range Exploration
  * Rating-based Selection

### 🧠 Advanced Search Technologies
- Intelligent Search Mechanisms
  * Word Completion
  * Smart Spell Checking
  * Reverse Indexing
  * AI-Powered Search Assistant
  * Autocorrect Suggestions

### 🌐 Dynamic Web Crawling
Real-time hotel data retrieval from:
- Expedia
- Hotels.com
- Triavgo.com
- Marriot.com
- Kayak.com

## 🔧 Installation Guide

### 1. Clone the Repository
```bash
git clone https://github.com/krish1195/elite-suites.git
cd elite-suites
```

### 2. Install Dependencies
#### Maven
```bash
mvn clean install
```

#### Gradle
```bash
gradle build
```

### 3. Configure ChromeDriver
1. Download compatible ChromeDriver
2. Add to system PATH
3. Update WebDriver configuration in code
